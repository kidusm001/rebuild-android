**Swipe between History's tabs.** Version code 18.

- **Swipe left or right** on History to move between Workouts, Exercises and Body. Tapping a tab still works too.
- **The tab indicator follows your finger** as you swipe, and each tab keeps its scroll position and search text when
  you come back to it.
- **Charts still read where you drag.** On the Body tab, a horizontal drag on a chart reads the chart; anywhere else
  on the page, it switches tabs.

Nothing stored changed, and installing over any earlier version keeps all data. Export a backup first, then install
the APK below with Android Files, or `adb install -r rebuild-0.1.17.apk`. It's signed with the same key as every
earlier version; the release workflow checks the certificate before publishing.
