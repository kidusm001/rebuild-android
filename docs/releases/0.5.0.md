**A guided start, a home screen widget, and a new look.** Version code 25.

- **Guided setup:** a fresh install asks three questions (experience, days a week, equipment and unit), shows the weekly plan day by day before saving, and optionally sets up rest alerts. Plan gains a "Your plan" card and **Change split**, with new splits including Power and hypertrophy, Torso and limbs, Bro split and Arnold split.
- **Tips:** short first-time tips appear in place and never block you; **More › Tips** brings them back.
- **Today widget:** a home screen widget mirrors Today: the exercises before training, live progress with Resume, a large rest countdown with the next set, and the week plus Up next on rest days.
- **New look:** the app uses its own font, Archivo, everywhere, and Phosphor Bold icons, including a level barbell for Today and the app icon.
- **Motion:** screens, tabs, the receipt and each set's moments move without blank frames or pops.
- **Rest:** the rest bar fits one line in landscape, Skip can be undone for a few seconds, the bar slides away when a rest ends with Edge light or no alert, and the picture-in-picture timer keeps its amber look after a theme or text-size change.
- **Fixes:** History detail's stat tiles stack at 200% text; a wide logged set such as 31.25 kg × 12 no longer runs under its edit pencil; a plan started late in the week offers its first workout.

Backups move to version eight to store your split and equipment. Older backups still restore, and installing over any earlier version keeps all data. Export a backup first, then install the APK below with Android Files, or `adb install -r rebuild-0.5.0.apk`. It's signed with the same key as every earlier version; the release workflow checks the certificate before publishing.
