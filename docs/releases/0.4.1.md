**Reordering exercises that lands where you drop them.** Version code 24.

- **Drag to reorder, fixed:** hold an exercise at the top of the workout and drag it. The pill stays under your finger and lands exactly where you let go. The strip no longer jumps when you drag the first exercise, and the pill no longer falls behind your finger and drops a place short.
- **Gentler edges:** hold the pill near either edge and the strip scrolls slowly, faster only the closer you get, at most about one exercise a second. Before, it raced past several at once.
- **Smoother drop:** the pill eases into its new place instead of snapping.
- **Hold menu:** a move chosen right after letting go of a hold now shows straight away.

Nothing stored changed, and installing over any earlier version keeps all data. Export a backup first, then install the APK below with Android Files, or `adb install -r rebuild-0.4.1.apk`. It's signed with the same key as every earlier version; the release workflow checks the certificate before publishing.
