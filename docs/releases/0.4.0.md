**Your heaviest set over time, and a tidier workout screen.** Version code 23.

- **Heaviest-set chart:** each exercise in History charts your heaviest set each workout, with the reps on every dot. It opens on the last 3 months (All shows everything), the latest set is ringed, and touching a dot shows its day and workout. If an exercise is in two workouts, "Split by workout" draws one line for each. The first touch on any chart now reads it.
- **Exercise list with numbers:** History's exercise list shows each exercise's latest top set and sorts by Recent, A–Z or muscle. Records say what each rep count was before.
- **Calmer workout screen:** the exercise header is two lines, the name with its unit and then the target. Plate loads read "6 plates × 15", so they stay on one line at larger font sizes, and drops never split from their reps.
- **Presses and fields:** tapping buttons and tabs shows amber instead of a grey or white flash. Text fields share one filled look, and a focused field's highlight wraps only the box, not the hint beneath it.

Nothing stored changed, and installing over any earlier version keeps all data. Export a backup first, then install the APK below with Android Files, or `adb install -r rebuild-0.4.0.apk`. It's signed with the same key as every earlier version; the release workflow checks the certificate before publishing.
