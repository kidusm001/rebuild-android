**A modern redesign.** Version code 20.

- **New look:** warm tonal cards instead of outlines and dividers, bold condensed numbers for anything you read at a glance, and vivid amber main buttons, in light and dark. Dialogs use the same pill buttons as the rest of the app.
- **Rest timer:** a full-width amber sheet with a large countdown, +30 s and Skip. Rest times are now chosen with minute and second wheels and one-tap choices instead of typed seconds.
- **Logging:** large number tiles for kg, reps and RIR with the target in each label; a set with drops reads exactly like any other set; unlikely loads ask before saving.
- **History:** redesigned charts with an amber trend line and large readouts, the calendar and muscle bars in cards, grouped lists, and Minutes, Working sets and Exercises tiles on each finished workout.
- **Clearer everywhere:** one name per training phase, every action looks like a button, a stronger backup reminder, and better screen-reader labels.

Nothing stored changed, and installing over any earlier version keeps all data. Export a backup first, then install the APK below with Android Files, or `adb install -r rebuild-0.2.0.apk`. It's signed with the same key as every earlier version; the release workflow checks the certificate before publishing.
