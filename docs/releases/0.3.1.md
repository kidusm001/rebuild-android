**Hold to rearrange, and a calmer dark mode.** Version code 22.

- **Rearrange mid-workout:** hold an exercise at the top of the workout and drag it to change today's order. Hold and let go instead for a menu to move it a place or remove it from today. A planned exercise is only skipped for today and stays in your plan; one you added today is removed, with a confirmation if sets are logged. Your plan's order never changes.
- **Calmer dark mode:** the amber buttons, rest bar and full-screen rest alerts no longer glare on black. Charts, highlights and amber text keep their full colour.

Nothing stored changed, and installing over any earlier version keeps all data. Export a backup first, then install the APK below with Android Files, or `adb install -r rebuild-0.3.1.apk`. It's signed with the same key as every earlier version; the release workflow checks the certificate before publishing.
