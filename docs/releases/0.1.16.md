**Drops never count as sets.** Version code 17.

- **A drop never counts as a working set.** After a set, *Add drop to set N* adds the drop to that set. The working-set
  count doesn't change, and no "extra" mark or "Above the advisory upper" warning appears.
- **The next entry stays a drop**, with empty fields, until you log a normal set, choose another type or tap Cancel.
  Before, every save reset the entry, so a second drop was logged as a new set: counted, marked extra and warned about.
- **No more separate "Drop set" type** in the set-type menu. It started a new, counted set, which is how drops became
  sets. Rest-pause stays, because a rest-pause set really is one set.
- **Fix earlier drops yourself:** open a set that was logged as a drop set on its own, then tap *Make them drops of set
  N*. It becomes part of the set before it, every value is kept, and it stops counting. This works in a live workout
  and in History.

Nothing stored changed format, and installing over any earlier version keeps all data. Export a backup first, then
install the APK below with Android Files, or `adb install -r rebuild-0.1.16.apk`. It is signed with the same key as
every earlier version; the release workflow checks the certificate before publishing.
